KCC TESDA and Technical‑Vocational Programs
A third‑party TESDA course directory lists the following qualifications associated with KCC: Computer Hardware Servicing NC II, Dressmaking NC II, Electrical Installation and Maintenance NC II, Programming NC IV, and Shielded Metal Arc Welding NC I. Some directory entries contain different training‑hour records for the same qualification. These are third‑party directory listings, not confirmation that all programs are currently active.
