# KCC TESDA AND TECHNICAL-VOCATIONAL PROGRAMS



A third-party TESDA course directory lists the following qualifications associated with KCC:



1. Computer Hardware Servicing NC II

2. Dressmaking NC II

3. Electrical Installation and Maintenance NC II

4. Programming NC IV

5. Shielded Metal Arc Welding NC I



Some directory entries contain different training-hour records for the same qualification.



## IMPORTANT



These are third-party directory listings, not confirmation that all programs are currently active.
